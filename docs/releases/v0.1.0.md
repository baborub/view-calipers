# view-calipers v0.1.0

The first public release: a Windows media browser for images, videos, comics, documents, and 3D models.

### Highlights

- Always-available This PC tree, bookmarks, and clickable path breadcrumbs.
- Two independent browser panes with duplicatable and lockable tabs.
- Adjustable split preview: Pane 1 above Pane 2, including simultaneous video playback.
- Background thumbnail generation, persistent caching, folder / archive covers, and EXIF orientation.
- ZIP / CBZ, RAR / CBR, and 7z / CB7 image browsing.
- Video scrubbing, A–B playback markers, clip / section repeat, and optional GPU decoding.
- PDF page scrubbing and Markdown rendering.
- Interactive OBJ, FBX, glTF / GLB, and USD-family mesh previews via Blender.
- Fullscreen viewing and customizable shortcuts.

### Installation

Download `view-calipers-v0.1.0-windows-x64.zip`, extract it, and run `view-calipers.exe`.

Requires Windows 10 / 11 x64 and an OpenGL 3.3 capable graphics driver. Install the Microsoft Visual C++ Redistributable (x64) if needed. Install FFmpeg, FFprobe, and FFplay for video, and Blender for 3D. These tools are not bundled.

### Known limits

The executable is unsigned. Video previews are limited to approximately 960 × 540 pixels at 24 fps. 3D previews show static geometry and base colors, without textures or animation. Animated images show a still frame. Archive previews support images; password-protected archives are unsupported. Tabs and playback ranges are session-only.
